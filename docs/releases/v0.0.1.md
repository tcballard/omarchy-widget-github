Your GitHub contribution graph, on the Omarchy desktop. First testing preview.

- Small, Medium and Large heatmaps, with daily counts and an editable username.
- GitHub green or your theme colours. Cached public data; no token needed.

Requires the [updated Widget Core](https://github.com/tcballard/omarchy-widget-github/tree/v0.0.1#try-it). Automated checks pass; live XPS network and desktop testing is still pending. Public totals can differ from your signed-in graph.

Try the three sizes, change the username, and restart Core. v0.1.0 is the supported-release target across the widgets.
